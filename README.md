# 호원 작은 산책 · 개인 비상업 팬 데모

호원중 학생을 위해 만든 기간 한정 팬 데모입니다. 먼작귀·학교 공식 서비스가 아닙니다. 공개 운영은 2026-10-31까지(Asia/Seoul)이며, 2026-11-01부터 비공개 기술 테스트만 진행할 예정입니다. 삭제 요청 시 운영자가 즉시 중단·삭제를 처리합니다. 원작 캐릭터 권리는 해당 권리자에게 있습니다.

## 이용

1. 안내 친구를 고르고 ‘탐험 시작’을 누릅니다.
2. 안내 지점에 도착하면 설명을 먼저 읽습니다.
3. ‘미니게임 시작’을 눌러 미션을 완료하고 다음 지점으로 이동합니다.
4. 여덟 곳을 둘러본 뒤 완주 요약과 작별 인사를 만납니다.

직접 걷기는 W/S 앞뒤, A/D 방향 전환, Shift 달리기입니다. 모바일은 조이스틱과 달리기 버튼을 사용합니다. 화면 드래그는 자유 시점이며 ‘친구 따라가기’로 돌아옵니다. 휠은 추적 거리, 설정의 FOV는 시야각을 바꿉니다.

자동 이동을 시작한 지 15초가 지나도 도착하지 않으면 ‘안내 지점으로 바로 이동’, ‘직접 걷기’, ‘계속 기다리기’를 선택할 수 있습니다. 정상 경로도 15초보다 길 수 있으므로 이 안내 자체가 오류 판정은 아닙니다.

기본 화면은 간단 모드입니다. 주요 조작 여섯 개에는 글자 레이블이 있고, 자동 산책 속도 0.5/1/1.5배와 화질·음악·환경은 설정에서 바꿉니다. BGM은 기본 꺼짐이며 클릭 이후에만 재생합니다.

## 데이터와 고지

앱에는 로그인, 개인정보 입력, 서버 저장, 진행 저장, 분석, 광고, 후원 기능이 없습니다. 점수와 진행은 현재 열린 화면에서만 유지되고 새로고침하면 초기화됩니다. 정적 호스팅 제공자는 서비스 운영을 위한 기본 접속 기록을 처리할 수 있습니다. 외부 폰트/CDN 요청은 사용하지 않습니다.

학교 모델은 외관을 참고한 근사 3D 모델이며 실제 시설 위치나 이동 안전을 보증하지 않습니다. 출처와 권리 구분은 `CREDITS.md`, 이용 조건은 `LICENSE`, 배포 라이브러리 고지는 `public/THIRD_PARTY_NOTICES.txt`에 기록합니다.

## 개발 및 검수

Node.js 22 이상: `npm ci`, `npm test`, `npm run build`. 정적 결과는 `dist/`에 생성됩니다. 자동 검사는 생산 이동 함수·입력·도착·설명·미니게임·엔딩을 실행합니다. 실제 휴대폰·GPU 화면·실제 학생 대상 사용성은 별도 검수가 필요합니다.

스테이지 미니게임 변경은 승인 검토용 브랜치입니다. 승인받은 SHA만 main에 반영하며, 문제 발생 시 기준 커밋 `800a608`로 복원합니다. 검토 브랜치 작성은 게시 승인을 대신하지 않습니다. 종료 시 호스팅 공개 중단과 비공개 테스트 환경 확인이 별도로 필요합니다. 날짜 고지나 클라이언트 코드만으로 접근 제한을 보장하지 않습니다.

## 스테이지 미니게임

8개 학교 이야기를 읽은 뒤 명시적으로 시작하는 짧은 학습용 가상 미션입니다. 실제 학교 사실은 기존 소개 자료와 구분하며, 미션 선택은 학교의 실제 절차나 제도가 아닙니다. 모든 조작은 탭 또는 Tab/Enter로 가능하고 드래그·시간 제한·계정·영구 점수 기록이 없습니다. 닫으면 같은 미션을 이어 할 수 있고, 다시 하기는 해당 미션의 시도만 초기화합니다. 전체 재시작은 모든 산책 진행을 초기화합니다. 여덟 미니게임 뒤에는 반복 OX 없이 요약과 작별로 이어집니다.

## 모바일 조작 보완

빈 장면을 가볍게 탭해도 추적 시점을 유지합니다. 손가락을 의도적으로 끌거나 두 손가락으로 장면을 조작하면 자유 시점으로 전환하며, 드래그·취소·여러 손가락 제스처를 캐릭터 선택으로 처리하지 않습니다. 화면 회전이나 크기 변경 시 이동·달리기 입력을 안전하게 해제합니다. 미니게임은 상단 닫기와 하단 이어 하기 버튼 모두 진행을 유지합니다.

모바일 레이아웃 검사는 CSS 구조·치수 조건과 생산 이벤트 핸들러를 대상으로 했습니다. 실제 휴대폰, 모바일 브라우저의 네이티브 제스처, WebGL 화면·FPS·화면 읽기 프로그램은 별도 검수가 필요합니다.
