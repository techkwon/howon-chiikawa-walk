# 호원 작은 산책 · Howon Little Walk

호원중학교의 사진 기반 근사 3D 학교와 치이카와, 하치와레, 우사기 팬 캐릭터가 함께하는 비상업적 웹 산책 실험입니다.

## 실행

Node.js 22 이상에서 `npm ci`, `npm run dev`를 실행합니다. `npm test`는 외부 이동 경로의 건물 교차와 연결성을 검사합니다. `npm run build`로 정적 `dist/`를 만들고 `npm run preview`로 확인합니다.

GitHub Pages용 Actions가 포함되어 있습니다. 저장소의 Pages 배포 소스를 GitHub Actions로 선택하면 main 브랜치 갱신 때 테스트·빌드 후 배포됩니다. Vite 상대 base 설정으로 프로젝트 하위 경로에서 작동합니다.

## 조작

- 드래그로 회전, 휠 또는 두 손가락으로 확대·축소
- 친구와 목적지를 선택하면 지정된 외부 경로로 산책
- 따라가기 / 전체 보기, 일시 정지, 속도, 초기화, 사진 저장
- 고화질 버튼으로 그림자와 해상도를 낮출 수 있습니다.

## 표현과 권리

공식 서비스가 아닌 비상업적 팬 제작물입니다. 치이카와 관련 캐릭터의 권리는 원권리자에게 있습니다. 캐릭터는 이 프로젝트에서 직접 생성한 절차적 3D 형태이며, 공식 모델·음원·음악을 복제하지 않았습니다. 학교 모델은 공개 학교 사진을 참고한 시각적 근사이며 실제 치수·건물 안전 정보·정확한 동선을 보증하지 않습니다. 학생의 이름, 사진, 위치 또는 계정 정보를 사용하지 않습니다.

학교 모델은 기존 Blender 제작물에서 GLB로 변환했습니다. 앱은 서버·계정·추적 도구 없이 브라우저에서 실행됩니다. 글꼴은 Google Fonts에서 요청할 수 있으며 접근 실패 시 시스템 글꼴을 사용합니다.
